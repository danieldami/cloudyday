# Nova X - Social Media Marketing Agency

A modern, responsive website for Nova X social media marketing agency, built with React, TypeScript, and Tailwind CSS.

## Features

- 🎨 Modern, responsive design matching the Webflow original
- ⚡ Fast development with Vite
- 🎯 TypeScript for type safety
- 💨 Tailwind CSS for styling
- 📱 Mobile-first responsive design
- ✨ Smooth animations and transitions

## Sections

- **Hero Section** - Eye-catching introduction with call-to-action buttons
- **Services** - Social Media Marketing, Digital Advertising, Engagement Growth
- **Team** - Meet the team members with their roles and descriptions
- **FAQs** - Interactive accordion with common questions
- **Case Studies** - Showcase of client work
- **Testimonials** - Client reviews and feedback
- **Newsletter** - Email subscription form
- **Footer** - Contact information and quick links

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and visit `http://localhost:5173`

### Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory.

### Preview Production Build

```bash
npm run preview
```
